    57→    57→    57→### 1.1 Q1: What product should be ordered?
    58→    58→    58→
    59→    59→    59→**Logic:** A product appears on the recommended order list when:
    60→    60→    60→
    61→    61→    61→```
    62→    62→    62→Current Available Stock < Reorder Point
    63→    63→    63→```
    64→    64→    64→
    65→    65→    65→Where:
    66→    66→    66→
    67→    67→    67→```
    68→    68→    68→Reorder Point = (Daily Consumption Rate × Lead Time) + Safety Stock
    69→    69→    69→```
    70→    70→    70→
    71→    71→    71→**Filterable dimensions:**
    72→    72→    72→| Filter | Values | Use Case |
    73→    73→    73→|--------|--------|----------|
    74→    74→    74→| Season | `winter`, `summer`, `monsoon`, `pre_winter`, `all_season` | "Show me winter-critical items" |
    75→    75→    75→| Motorcycle Model | `CD70`, `Pulsar150`, `Platina100`, etc. | "Only CD70 parts" |
    76→    76→    76→| Category | `brake_system`, `chain_sprocket`, `engine`, `electrical`, `body`, `riding_gear` | "Brake parts only" |
    77→    77→    77→| Urgency | `critical`, `high`, `normal`, `low` | "What needs ordering NOW?" |
    78→    78→    78→| CNY Risk | `true`, `false` | "Which orders have CNY risk?" |
    79→    79→    79→| Shipment Mode | `sea`, `air` | "Air-ship the urgent ones" |
    80→    80→    80→
    81→    81→    81→**Output:** Filterable Recommended Order List (sorted by urgency descending)
    82→    82→    82→
    83→    83→    83→### 1.2 Q2: What quantity should be ordered?
    84→    84→    84→
    85→    85→    85→**Core formula:**
    86→    86→    86→
    87→    87→    87→```
    88→    88→    88→Recommended Qty = max(EOQ, (Forecasted Demand + Safety Stock) - Current Stock - Pending Orders)
    89→    89→    89→```
    90→    90→    90→
    91→    91→    91→**Constraints applied in order:**
    92→    92→    92→
    93→    93→    93→```
    94→    94→    94→┌────────────────────────────────────────────────────────────────┐
    95→    95→    95→│  1. Supplier MOQ:   qty >= MOQ    (cannot order below minimum) │
    96→    96→    96→│  2. Warehouse Cap:  qty <= Max Stock - Current Stock            │
    97→    97→    97→│  3. Overstock:      If current > max_stock, qty = 0 (draw down)│
    98→    98→    98→│  4. Seasonal Cap:   qty <= seasonal_demand_ceiling              │
    99→    99→    99→└────────────────────────────────────────────────────────────────┘
   100→   100→   100→```
   101→   101→   101→
   102→   102→   102→### 1.3 Q3: WHEN should the product be ordered?
   103→   103→   103→
   104→   104→   104→**This is the single most valuable algorithm in the entire system.**
   105→   105→   105→
   106→   106→   106→The Order Trigger Date accounts for:
   107→   107→   107→- ✅ Manufacturing lead time (supplier-specific)
   108→   108→   108→- ✅ Shipment time (sea or air route)
   109→   109→   109→- ✅ Customs clearance time (Chittagong port or Dhaka airport)
   110→   110→   110→- ✅ Chinese New Year shutdown impact
   111→   111→   111→- ✅ Seasonal demand acceleration/deceleration
   112→   112→   112→- ✅ Safety buffer before stock hits critical level
   113→   113→   113→
   114→   114→   114→**Why this is so valuable:** A BD motorcycle parts importer who orders too early ties up capital in warehouse inventory. One who orders too late faces stockouts during peak season. The precise trigger date **maximizes cash flow efficiency while minimizing stockout risk** — and that is worth the entire SaaS subscription.

   272→   272→   272→### 2.6 Lead Time Variability Model
   273→   273→   273→
   274→   274→   274→Lead times are NOT deterministic. The system models them as distributions for Monte Carlo simulation:
   275→   275→   275→
   276→   276→   276→```python
   277→   277→   277→from dataclasses import dataclass
   278→   278→   278→from typing import Optional
   279→   279→   279→
   280→   280→   280→@dataclass
   281→   281→   281→class LeadTimeDistribution:
   282→   282→   282→    """
   283→   283→   283→    Probabilistic model of each lead time component.
   284→   284→   284→    Used for Monte Carlo simulation of order arrival dates.
   285→   285→   285→    """
   286→   286→   286→    # Manufacturing
   287→   287→   287→    mfg_best: int = 75       # Best case (days)
   288→   288→   288→    mfg_likely: int = 90     # Most likely (days)
   289→   289→   289→    mfg_worst: int = 120     # Worst case (days)
   290→   290→   290→    
   291→   291→   291→    # Shipment (Sea)
   292→   292→   292→    ship_sea_best: int = 45
   293→   293→   293→    ship_sea_likely: int = 52
   294→   294→   294→    ship_sea_worst: int = 65
   295→   295→   295→    
   296→   296→   296→    # Shipment (Air)
   297→   297→   297→    ship_air_best: int = 5
   298→   298→   298→    ship_air_likely: int = 8
   299→   299→   299→    ship_air_worst: int = 12
   300→   300→   300→    
   301→   301→   301→    # Customs (Sea/Chittagong)
   302→   302→   302→    customs_sea_best: int = 7
   303→   303→   303→    customs_sea_likely: int = 10
   304→   304→   304→    customs_sea_worst: int = 18
   305→   305→   305→    
   306→   306→   306→    # Customs (Air/Dhaka)
   307→   307→   307→    customs_air_best: int = 2
   308→   308→   308→    customs_air_likely: int = 3
   309→   309→   309→    customs_air_worst: int = 5
   310→   310→   310→
   311→   311→   311→    def total_sea_best(self) -> int:
   312→   312→   312→        return self.mfg_best + self.ship_sea_best + self.customs_sea_best  # 127
   313→   313→   313→    
   314→   314→   314→    def total_sea_likely(self) -> int:
   315→   315→   315→        return self.mfg_likely + self.ship_sea_likely + self.customs_sea_likely  # 152
   316→   316→   316→    
   317→   317→   317→    def total_sea_worst(self) -> int:
   318→   318→   318→        return self.mfg_worst + self.ship_sea_worst + self.customs_sea_worst  # 203
   319→   319→   319→    
   320→   320→   320→    def total_air_best(self) -> int:
   321→   321→   321→        return self.mfg_best + self.ship_air_best + self.customs_air_best  # 82
   322→   322→   322→    
   323→   323→   323→    def total_air_likely(self) -> int:
   324→   324→   324→        return self.mfg_likely + self.ship_air_likely + self.customs_air_likely  # 101
   325→   325→   325→    
   326→   326→   326→    def total_air_worst(self) -> int:
   327→   327→   327→        return self.mfg_worst + self.ship_air_worst + self.customs_air_worst  # 137
   328→   328→   328→```
   329→   329→   329→
   330→   330→   330→**P90 lead times** (90% of orders arrive within this time):
   331→   331→   331→```
   332→   332→   332→  Sea P90:  ~175 days (use this for conservative planning)
   333→   333→   333→  Air P90:  ~115 days (use this for conservative air planning)
   334→   334→   334→```

   338→   338→   338→## 3. Chinese New Year (CNY) Impact Model
   339→   339→   339→
   340→   340→   340→### 3.1 CNY Shutdown Facts
   341→   341→   341→
   342→   342→   342→> This is the single biggest disruption to BD–China motorcycle parts supply chain. Every year, importers who fail to plan for CNY face 2–3 month stockouts. **TrimedCast is the first system to model this explicitly.**
   343→   343→   343→
   344→   344→   344→```
   345→   345→   345→  ┌─────────────────────────────────────────────────────────────────────┐
   346→   346→   346→  │  CHINESE NEW YEAR — THE ANNUAL SUPPLY CHAIN BLACK HOLE            │
   347→   347→   347→  │                                                                     │
   348→   348→   348→  │  • Chinese factories shut down for 2–4 weeks around Lunar New Year │
   349→   349→   349→  │  • No new production starts during the shutdown window              │
   350→   350→   350→  │  • Existing production may pause mid-way                            │
   351→   351→   351→  │  • Post-CNY restart is gradual (factories don't all restart Day 1) │
   352→   352→   352→  │  • Effective delay: 20–30 days added to any order touching CNY     │
   353→   353→   353→  │  • Pre-CNY rush: Suppliers prioritize older orders, new orders     │
   354→   354→   354→  │    placed in December/January may get delayed further               │
   355→   355→   355→  │                                                                     │
   356→   356→   356→  └─────────────────────────────────────────────────────────────────────┘
   357→   357→   357→```
   358→   358→   358→
   359→   359→   359→### 3.2 CNY Risk Detection Algorithm
   360→   360→   360→
   361→   361→   361→```python
   362→   362→   362→from datetime import date, timedelta
   363→   363→   363→from dataclasses import dataclass
   364→   364→   364→from typing import Optional
   365→   365→   365→
   366→   366→   366→@dataclass
   367→   367→   367→class CNYRisk:
   368→   368→   368→    """Result of CNY overlap analysis."""
   369→   369→   369→    has_risk: bool
   370→   370→   370→    overlap_days: int
   371→   371→   371→    original_trigger_date: Optional[date]
   372→   372→   372→    revised_trigger_date: Optional[date]
   373→   373→   373→    strategy: str           # 'before_cny', 'after_cny', 'none'
   374→   374→   374→    additional_delay_days: int  # Extra days added to lead time
   375→   375→   375→    explanation: str
   376→   376→   376→
   377→   377→   377→
   378→   378→   378→def check_cny_risk(
   379→   379→   379→    order_date: date,
   380→   380→   380→    mfg_days: int,
   381→   381→   381→    cny_start: date,
   382→   382→   382→    cny_end: date,
   383→   383→   383→    buffer_days: int = 5,  # Days before CNY when factories start winding down
   384→   384→   384→) -> CNYRisk:
   385→   385→   385→    """
   386→   386→   386→    Check if the manufacturing period overlaps with CNY shutdown.
   387→   387→   387→    
   388→   388→   388→    Manufacturing period: order_date to (order_date + mfg_days)
   389→   389→   389→    CNY shutdown: cny_start to cny_end
   390→   390→   390→    
   391→   391→   391→    Factories start winding down `buffer_days` before cny_start,
   392→   392→   392→    so effective CNY impact window is (cny_start - buffer) to cny_end.
   393→   393→   393→    
   394→   394→   394→    Args:
   395→   395→   395→        order_date: When the order would be placed
   396→   396→   396→        mfg_days: Manufacturing lead time in days
   397→   397→   397→        cny_start: First day of CNY factory shutdown
   398→   398→   398→        cny_end: Last day of CNY factory shutdown (factories restart next day)
   399→   399→   399→        buffer_days: Pre-CNY wind-down period (default 5)
   400→   400→   400→    
   401→   401→   401→    Returns:
   402→   402→   402→        CNYRisk with overlap analysis and resolution strategy
   403→   403→   403→    """
   404→   404→   404→    # Effective CNY window (includes pre-CNY wind-down)
   405→   405→   405→    effective_cny_start = cny_start - timedelta(days=buffer_days)
   406→   406→   406→    
   407→   407→   407→    # Manufacturing period
   408→   408→   408→    mfg_start = order_date + timedelta(days=2)  # 2 days order processing
   409→   409→   409→    mfg_end = mfg_start + timedelta(days=mfg_days)
   410→   410→   410→    
   411→   411→   411→    # Check overlap between manufacturing period and effective CNY window
   412→   412→   412→    overlap_start = max(mfg_start, effective_cny_start)
   413→   413→   413→    overlap_end = min(mfg_end, cny_end + timedelta(days=3))  # +3 for gradual restart
   414→   414→   414→    
   415→   415→   415→    if overlap_start < overlap_end:
   416→   416→   416→        overlap_days = (overlap_end - overlap_start).days
   417→   417→   417→        
   418→   418→   418→        # Determine best strategy
   419→   419→   419→        # Strategy A: Can we complete manufacturing before CNY starts?
   420→   420→   420→        latest_start_before_cny = effective_cny_start - timedelta(days=mfg_days) - timedelta(days=2)
   421→   421→   421→        
   422→   422→   422→        if order_date <= latest_start_before_cny:
   423→   423→   423→            strategy = 'before_cny'
   424→   424→   424→            additional_delay = 0
   425→   425→   425→            explanation = (
   426→   426→   426→                f"Manufacturing overlaps CNY by {overlap_days} days. "
   427→   427→   427→                f"However, ordering by {latest_start_before_cny} ensures "
   428→   428→   428→                f"manufacturing completes before CNY shutdown."
   429→   429→   429→            )
   430→   430→   430→        else:
   431→   431→   431→            strategy = 'after_cny'
   432→   432→   432→            # Full CNY delay: shutdown period + gradual restart
   433→   433→   433→            cny_shutdown_days = (cny_end - effective_cny_start).days + 3  # +3 restart
   434→   434→   434→            additional_delay = cny_shutdown_days
   435→   435→   435→            explanation = (
   436→   436→   436→                f"Manufacturing overlaps CNY by {overlap_days} days. "
   437→   437→   437→                f"Cannot complete before CNY. Effective delay: {cny_shutdown_days} days. "
   438→   438→   438→                f"Recommend ordering after CNY ({cny_end + timedelta(days=1)})."
   439→   439→   439→            )
   440→   440→   440→        
   441→   441→   441→        return CNYRisk(
   442→   442→   442→            has_risk=True,
   443→   443→   443→            overlap_days=overlap_days,
   444→   444→   444→            original_trigger_date=order_date,
   445→   445→   445→            revised_trigger_date=None,  # Set by caller based on strategy
   446→   446→   446→            strategy=strategy,
   447→   447→   447→            additional_delay_days=additional_delay,
   448→   448→   448→            explanation=explanation,
   449→   449→   449→        )
   450→   450→   450→    
   451→   451→   451→    # No overlap — safe
   452→   452→   452→    return CNYRisk(
   453→   453→   453→        has_risk=False,
   454→   454→   454→        overlap_days=0,
   455→   455→   455→        original_trigger_date=order_date,
   456→   456→   456→        revised_trigger_date=None,
   457→   457→   457→        strategy='none',
   458→   458→   458→        additional_delay_days=0,
   459→   459→   459→        explanation="Manufacturing period does not overlap with CNY shutdown.",
   460→   460→   460→    )
   461→   461→   461→```
   462→   462→   462→
   463→   463→   463→### 3.3 CNY Resolution Strategies
   464→   464→   464→
   465→   465→   465→```
   466→   466→   466→  ┌─────────────────────────────────────────────────────────────────────────┐
   467→   467→   467→  │                                                                         │
   468→   468→   468→  │  STRATEGY A: ORDER BEFORE CNY (Preferred)                               │
   469→   469→   469→  │  ──────────────────────────────────────                                 │
   470→   470→   470→  │  Place order early enough that manufacturing completes before CNY.      │
   471→   471→   471→  │  Required: order_date ≤ cny_start - mfg_days - buffer                  │
   472→   472→   472→  │  Pro:  No delay, goods arrive on original schedule                      │
   473→   473→   473→  │  Con:  Requires earlier capital outlay, may increase holding cost       │
   474→   474→   474→  │                                                                         │
   475→   475→   475→  │  STRATEGY B: ORDER AFTER CNY (Fallback)                                 │
   476→   476→   476→  │  ─────────────────────────────────────                                  │
   477→   477→   477→  │  Accept the delay. Place order after CNY ends.                          │
   478→   478→   478→  │  order_date = cny_end + 1                                               │
   479→   479→   479→  │  Adds CNY shutdown period (~25-35 days) to effective lead time          │
   480→   480→   480→  │  Pro:  No rush, standard order process                                  │
   481→   481→   481→  │  Con:  Stockout risk if safety stock is insufficient during CNY period  │
   482→   482→   482→  │                                                                         │
   483→   483→   483→  │  STRATEGY C: PARTIAL ORDER (Critical items only)                        │
   484→   484→   484→  │  ─────────────────────────────────────                                  │
   485→   485→   485→  │  Order critical/high-margin items before CNY (Strategy A)              │
   486→   486→   486→  │  Order non-critical items after CNY (Strategy B)                       │
   487→   487→   487→  │  Pro:  Balances capital efficiency with stockout prevention             │
   488→   488→   488→  │  Con:  Two shipments, more logistics complexity                         │
   489→   489→   489→  │                                                                         │
   490→   490→   490→  │  STRATEGY D: AIR ROUTE ESCAPE (Emergency)                               │
   491→   491→   491→  │  ─────────────────────────────────────                                  │
   492→   492→   492→  │  If stockout is imminent and CNY blocks sea route,                      │
   493→   493→   493→  │  switch to air route to reduce shipment time by ~44 days               │
   494→   494→   494→  │  Pro:  Fastest resolution                                               │
   495→   495→   495→  │  Con:  8x freight cost — use only for high-margin/critical items       │
   496→   496→   496→  │                                                                         │
   497→   497→   497→  └─────────────────────────────────────────────────────────────────────────┘
   498→   498→   498→```
   499→   499→   499→
   500→   500→   500→**Strategy selection algorithm:**
   501→   501→   501→
   502→   502→   502→```python
   503→   503→   503→def select_cny_strategy(
   504→   504→   504→    days_until_stockout: int,
   505→   505→   505→    cny_delay_days: int,
   506→   506→   506→    item_margin_pct: float,
   507→   507→   507→    item_urgency: str,
   508→   508→   508→    can_air_ship: bool,
   509→   509→   509→    air_cost_multiplier: float = 8.0,
   510→   510→   510→) -> str:
   511→   511→   511→    """
   512→   512→   512→    Automatically select the best CNY resolution strategy.
   513→   513→   513→    
   514→   514→   514→    Decision tree:
   515→   515→   515→    1. If we have enough stock to survive CNY delay → Strategy B (order after)
   516→   516→   516→    2. If stockout before CNY ends AND high margin → Strategy A (order before)
   517→   517→   517→    3. If stockout imminent AND can air ship → Strategy D (air escape)
   518→   518→   518→    4. Otherwise → Strategy C (partial order)
   519→   519→   519→    """
   520→   520→   520→    # Can we survive the CNY delay with current stock?
   521→   521→   521→    if days_until_stockout > cny_delay_days + 30:  # +30 buffer
   522→   522→   522→        return 'after_cny'  # Strategy B
   523→   523→   523→    
   524→   524→   524→    # Stockout risk — try to order before CNY
   525→   525→   525→    if item_urgency in ('critical', 'high'):
   526→   526→   526→        return 'before_cny'  # Strategy A
   527→   527→   527→    
   528→   528→   528→    # Emergency: stockout imminent, consider air
   529→   529→   529→    if days_until_stockout <= 30 and can_air_ship and item_margin_pct >= 30:
   530→   530→   530→        return 'air_escape'  # Strategy D
   531→   531→   531→    
   532→   532→   532→    # Default: partial approach
   533→   533→   533→    return 'partial_order'  # Strategy C
   534→   534→   534→```

   536→   536→   536→### 3.4 Annual CNY Calendar (2025–2030)

   560→   560→   560→    year = target_date.year
   561→   561→   561→    # Check current year and next year (CNY might be early next year)
   562→   562→   562→    for y in [year, year + 1]:

   564→   564→   564→            cny = CNY_CALENDAR[y]

   566→   566→   566→            if target_date <= cny['shutdown_end']:

   696→   696→   696→def calculate_order_trigger(
   697→   697→   697→    sku_code: str,

   699→   699→   699→    current_stock: int,
   700→   700→   700→    safety_stock: int,

   706→   706→   706→    customs_days: Optional[int] = None,
   707→   707→   707→    forecasted_demand: int = 0,
   708→   708→   708→    qty_on_order: int = 0,
   709→   709→   709→    eoq: int = 0,
   710→   710→   710→    moq: int = 1,
   711→   711→   711→    today: Optional[date] = None,
   712→   712→   712→    cny_start: Optional[date] = None,
   713→   713→   713→    cny_end: Optional[date] = None,
   714→   714→   714→    buffer_days: int = 7,
   715→   715→   715→    order_processing_days: int = 2,
   716→   716→   716→    packing_loading_days: int = 2,

   720→   720→   720→) -> OrderTriggerResult:
   721→   721→   721→    """
   722→   722→   722→    ╔═════════════════════════════════════════════════════════════════╗
   723→   723→   723→    ║  THE CORE ALGORITHM: Calculate when, what, and how much to     ║
   724→   724→   724→    ║  order for a single SKU.                                       ║
   725→   725→   725→    ║                                                                 ║
   726→   726→   726→    ║  This function answers ALL THREE QUESTIONS:                     ║
   727→   727→   727→    ║    Q1: What product?  → needs_order, stock_status               ║
   728→   728→   728→    ║    Q2: What qty?      → recommended_qty                         ║
   729→   729→   729→    ║    Q3: When?          → order_trigger_date, timeline, urgency   ║
   730→   730→   730→    ╚═════════════════════════════════════════════════════════════════╝
   731→   731→   731→    
   732→   732→   732→    Args:
   733→   733→   733→        sku_code: Product SKU code
   734→   734→   734→        product_name: Human-readable product name
   735→   735→   735→        current_stock: Current available inventory (units)
   736→   736→   736→        safety_stock: Minimum stock level before stockout risk
   737→   737→   737→        max_stock: Maximum warehouse capacity for this SKU
   738→   738→   738→        daily_consumption_rate: Average units consumed per day
   739→   739→   739→        mfg_days: Manufacturing lead time (supplier-specific)
   740→   740→   740→        shipment_mode: SEA or AIR
   741→   741→   741→        shipment_days: Override for calculated shipment days
   742→   742→   742→        customs_days: Override for calculated customs days
   743→   743→   743→        forecasted_demand: Total forecasted demand for the planning period
   744→   744→   744→        qty_on_order: Units already on order (in pipeline)
   745→   745→   745→        eoq: Economic Order Quantity
   746→   746→   746→        moq: Supplier Minimum Order Quantity
   747→   747→   747→        today: Current date (defaults to date.today())
   748→   748→   748→        cny_start: CNY shutdown start date (None = no CNY check)
   749→   749→   749→        cny_end: CNY shutdown end date (None = no CNY check)
   750→   750→   750→        buffer_days: Safety buffer before stock hits safety level
   751→   751→   751→        order_processing_days: Days for supplier to acknowledge order
   752→   752→   752→        packing_loading_days: Days for packing and loading at port
   753→   753→   753→        warehouse_transport_days: Days for final transport to warehouse
   754→   754→   754→        qc_shelving_days: Days for QC check and shelving
   755→   755→   755→        monsoon_adjustment: Extra shipment days during monsoon (Jun-Sep)
   756→   756→   756→    
   757→   757→   757→    Returns:
   758→   758→   758→        OrderTriggerResult with complete analysis
   759→   759→   759→    """
   760→   760→   760→    if today is None:
   761→   761→   761→        today = date.today()
   762→   762→   762→    
   763→   763→   763→    # ──────────────────────────────────────────────────────────────
   764→   764→   764→    # STEP 1: Determine shipment and customs durations
   765→   765→   765→    # ──────────────────────────────────────────────────────────────
   766→   766→   766→    if shipment_days is None:
   767→   767→   767→        if shipment_mode == ShipmentMode.SEA:
   768→   768→   768→            shipment_days = 52 + monsoon_adjustment
   769→   769→   769→        else:
   770→   770→   770→            shipment_days = 8
   771→   771→   771→    
   772→   772→   772→    if customs_days is None:
   773→   773→   773→        customs_days = 10 if shipment_mode == ShipmentMode.SEA else 3
   774→   774→   774→    
   775→   775→   775→    # ──────────────────────────────────────────────────────────────
   776→   776→   776→    # STEP 2: Calculate Reorder Point (answers Q1)
   777→   777→   777→    # ──────────────────────────────────────────────────────────────
   778→   778→   778→    total_lead_time = mfg_days + shipment_days + customs_days
   779→   779→   779→    reorder_point = (daily_consumption_rate * total_lead_time) + safety_stock
   780→   780→   780→    
   781→   781→   781→    # Determine stock status
   782→   782→   782→    if current_stock <= safety_stock:
   783→   783→   783→        stock_status = 'at_safety'
   784→   784→   784→        needs_order = True
   785→   785→   785→    elif current_stock <= reorder_point:
   786→   786→   786→        stock_status = 'below_reorder'
   787→   787→   787→        needs_order = True
   788→   788→   788→    elif current_stock > max_stock:
   789→   789→   789→        stock_status = 'overstock'
   790→   790→   790→        needs_order = False
   791→   791→   791→    else:
   792→   792→   792→        stock_status = 'adequate'
   793→   793→   793→        needs_order = current_stock < reorder_point  # May still need to order for seasonal prep
   794→   794→   794→    
   795→   795→   795→    # ──────────────────────────────────────────────────────────────
   796→   796→   796→    # STEP 3: Calculate Order Trigger Date (answers Q3)
   797→   797→   797→    # ──────────────────────────────────────────────────────────────
   798→   798→   798→    
   799→   799→   799→    # 3a: When will stock hit safety stock level?
   800→   800→   800→    if daily_consumption_rate > 0:
   801→   801→   801→        days_until_safety_stock = (current_stock - safety_stock) / daily_consumption_rate
   802→   802→   802→    else:
   803→   803→   803→        days_until_safety_stock = float('inf')  # No consumption = no urgency
   804→   804→   804→    
   805→   805→   805→    safety_stock_hit_date = today + timedelta(days=max(0, days_until_safety_stock))
   806→   806→   806→    
   807→   807→   807→    # 3b: Order trigger = safety_stock_hit_date - total_lead_time - buffer
   808→   808→   808→    #     (We must order early enough that goods arrive BEFORE we hit safety stock)
   809→   809→   809→    order_trigger_date = safety_stock_hit_date - timedelta(days=total_lead_time) - timedelta(days=buffer_days)
   810→   810→   810→    
   811→   811→   811→    # ──────────────────────────────────────────────────────────────
   812→   812→   812→    # STEP 4: CNY Risk Assessment
   813→   813→   813→    # ──────────────────────────────────────────────────────────────
   814→   814→   814→    cny_risk = _assess_cny_risk(
   815→   815→   815→        order_trigger_date=order_trigger_date,
   816→   816→   816→        mfg_days=mfg_days,
   817→   817→   817→        cny_start=cny_start,
   818→   818→   818→        cny_end=cny_end,
   819→   819→   819→        today=today,
   820→   820→   820→        current_stock=current_stock,
   821→   821→   821→        safety_stock=safety_stock,
   822→   822→   822→        daily_consumption_rate=daily_consumption_rate,
   823→   823→   823→        buffer_days=buffer_days,
   824→   824→   824→        order_processing_days=order_processing_days,
   825→   825→   825→    )
   826→   826→   826→    
   827→   827→   827→    # If CNY risk detected, revise order trigger date
   828→   828→   828→    cny_delay_days = 0
   829→   829→   829→    if cny_risk.has_risk:
   830→   830→   830→        if cny_risk.strategy == CNYStrategy.BEFORE_CNY:
   831→   831→   831→            # Order early enough to finish before CNY
   832→   832→   832→            if cny_risk.latest_safe_order_date and cny_risk.latest_safe_order_date >= today:
   833→   833→   833→                order_trigger_date = min(order_trigger_date, cny_risk.latest_safe_order_date)
   834→   834→   834→        elif cny_risk.strategy == CNYStrategy.AFTER_CNY:
   835→   835→   835→            # Accept delay, order after CNY
   836→   836→   836→            if cny_risk.post_cny_order_date:
   837→   837→   837→                order_trigger_date = cny_risk.post_cny_order_date
   838→   838→   838→                cny_delay_days = cny_risk.additional_delay_days
   839→   839→   839→        cny_risk = dataclass_replace(cny_risk)  # Update if needed
   840→   840→   840→    
   841→   841→   841→    # ──────────────────────────────────────────────────────────────
   842→   842→   842→    # STEP 5: Build Complete Timeline
   843→   843→   843→    # ──────────────────────────────────────────────────────────────
   844→   844→   844→    timeline = _build_timeline(
   845→   845→   845→        order_trigger_date=order_trigger_date,
   846→   846→   846→        mfg_days=mfg_days,
   847→   847→   847→        shipment_days=shipment_days,
   848→   848→   848→        customs_days=customs_days,
   849→   849→   849→        order_processing_days=order_processing_days,
   850→   850→   850→        packing_loading_days=packing_loading_days,
   851→   851→   851→        warehouse_transport_days=warehouse_transport_days,
   852→   852→   852→        qc_shelving_days=qc_shelving_days,
   853→   853→   853→        cny_delay_days=cny_delay_days,
   854→   854→   854→    )
   855→   855→   855→    
   856→   856→   856→    # ──────────────────────────────────────────────────────────────
   857→   857→   857→    # STEP 6: Determine Urgency
   858→   858→   858→    # ──────────────────────────────────────────────────────────────
   859→   859→   859→    days_until_trigger = (order_trigger_date - today).days
   860→   860→   860→    
   861→   861→   861→    if days_until_trigger <= 0:
   862→   862→   862→        urgency = Urgency.CRITICAL  # OVERDUE — should have been ordered already!
   863→   863→   863→    elif days_until_trigger <= 30:
   864→   864→   864→        urgency = Urgency.CRITICAL
   865→   865→   865→    elif days_until_trigger <= 90:
   866→   866→   866→        urgency = Urgency.HIGH
   867→   867→   867→    elif days_until_trigger <= 180:
   868→   868→   868→        urgency = Urgency.NORMAL
   869→   869→   869→    else:
   870→   870→   870→        urgency = Urgency.LOW
   871→   871→   871→    
   872→   872→   872→    # ──────────────────────────────────────────────────────────────
   873→   873→   873→    # STEP 7: Calculate Recommended Order Quantity (answers Q2)
   874→   874→   874→    # ──────────────────────────────────────────────────────────────
   875→   875→   875→    qty_result = calculate_recommended_qty(
   876→   876→   876→        forecasted_demand=forecasted_demand,
   877→   877→   877→        safety_stock=safety_stock,
   878→   878→   878→        current_stock=current_stock,
   879→   879→   879→        qty_on_order=qty_on_order,
   880→   880→   880→        eoq=eoq,
   881→   881→   881→        moq=moq,
   882→   882→   882→        max_stock=max_stock,
   883→   883→   883→    )
   884→   884→   884→    
   885→   885→   885→    # ──────────────────────────────────────────────────────────────
   886→   886→   886→    # STEP 8: Recommend shipment mode
   887→   887→   887→    # ──────────────────────────────────────────────────────────────
   888→   888→   888→    recommended_mode = shipment_mode
   889→   889→   889→    if urgency == Urgency.CRITICAL and shipment_mode == ShipmentMode.SEA:
   890→   890→   890→        # Consider air for critical items (but only if it saves enough time)
   891→   891→   891→        if days_until_trigger <= 0:
   892→   892→   892→            recommended_mode = ShipmentMode.AIR
   893→   893→   893→    
   894→   894→   894→    # ──────────────────────────────────────────────────────────────
   895→   895→   895→    # STEP 9: Return complete result
   896→   896→   896→    # ──────────────────────────────────────────────────────────────
   897→   897→   897→    return OrderTriggerResult(
   898→   898→   898→        sku_code=sku_code,
   899→   899→   899→        product_name=product_name,
   900→   900→   900→        needs_order=needs_order,
   901→   901→   901→        reorder_point=round(reorder_point, 1),
   902→   902→   902→        current_stock=current_stock,
   903→   903→   903→        stock_status=stock_status,
   904→   904→   904→        recommended_qty=qty_result['recommended_qty'],
   905→   905→   905→        recommended_qty_breakdown=qty_result,
   906→   906→   906→        order_trigger_date=order_trigger_date,
   907→   907→   907→        timeline=timeline,
   908→   908→   908→        urgency=urgency,
   909→   909→   909→        days_until_trigger=days_until_trigger,
   910→   910→   910→        cny_risk=cny_risk,
   911→   911→   911→        recommended_shipment_mode=recommended_mode,
   912→   912→   912→        calculated_at=today,
   913→   913→   913→        total_lead_time_days=total_lead_time,
   914→   914→   914→    )

   917→   917→   917→def _assess_cny_risk(
   918→   918→   918→    order_trigger_date: date,
   919→   919→   919→    mfg_days: int,
   920→   920→   920→    cny_start: Optional[date],
   921→   921→   921→    cny_end: Optional[date],
   922→   922→   922→    today: date,
   923→   923→   923→    current_stock: int,
   924→   924→   924→    safety_stock: int,
   925→   925→   925→    daily_consumption_rate: float,
   926→   926→   926→    buffer_days: int,
   927→   927→   927→    order_processing_days: int,
   928→   928→   928→) -> CNYRiskAssessment:
   929→   929→   929→    """Assess CNY risk for a planned order."""
   930→   930→   930→    
   931→   931→   931→    # No CNY data provided
   932→   932→   932→    if cny_start is None or cny_end is None:
   933→   933→   933→        return CNYRiskAssessment(
   934→   934→   934→            has_risk=False, overlap_days=0,
   935→   935→   935→            effective_cny_start=today, cny_shutdown_start=today, cny_shutdown_end=today,
   936→   936→   936→            strategy=CNYStrategy.NONE, additional_delay_days=0,
   937→   937→   937→            latest_safe_order_date=None, post_cny_order_date=None,
   938→   938→   938→            explanation="No CNY window provided for analysis.",
   939→   939→   939→        )
   940→   940→   940→    
   941→   941→   941→    # Pre-CNY wind-down period (factories slow down 5 days before)
   942→   942→   942→    pre_cny_winddown = 5
   943→   943→   943→    effective_cny_start = cny_start - timedelta(days=pre_cny_winddown)
   944→   944→   944→    
   945→   945→   945→    # Manufacturing period
   946→   946→   946→    mfg_start = order_trigger_date + timedelta(days=order_processing_days)
   947→   947→   947→    mfg_end = mfg_start + timedelta(days=mfg_days)
   948→   948→   948→    
   949→   949→   949→    # Post-CNY restart buffer (factories don't all restart on day 1)
   950→   950→   950→    post_cny_restart_buffer = 3
   951→   951→   951→    effective_cny_end = cny_end + timedelta(days=post_cny_restart_buffer)
   952→   952→   952→    
   953→   953→   953→    # Check overlap
   954→   954→   954→    overlap_start = max(mfg_start, effective_cny_start)
   955→   955→   955→    overlap_end = min(mfg_end, effective_cny_end)
   956→   956→   956→    
   957→   957→   957→    if overlap_start < overlap_end:
   958→   958→   958→        overlap_days = (overlap_end - overlap_start).days
   959→   959→   959→        
   960→   960→   960→        # Calculate latest safe order date (Strategy A)
   961→   961→   961→        latest_safe = effective_cny_start - timedelta(days=mfg_days) - timedelta(days=order_processing_days)
   962→   962→   962→        
   963→   963→   963→        # Calculate post-CNY order date (Strategy B)
   964→   964→   964→        post_cny_order = cny_end + timedelta(days=post_cny_restart_buffer)
   965→   965→   965→        
   966→   966→   966→        # Total CNY shutdown period
   967→   967→   967→        cny_total_days = (effective_cny_end - effective_cny_start).days
   968→   968→   968→        
   969→   969→   969→        # Determine strategy
   970→   970→   970→        if latest_safe >= today:
   971→   971→   971→            strategy = CNYStrategy.BEFORE_CNY
   972→   972→   972→            additional_delay = 0
   973→   973→   973→            explanation = (
   974→   974→   974→                f"⚠️ CNY RISK: Manufacturing overlaps CNY by {overlap_days} days. "
   975→   975→   975→                f"STRATEGY A: Order by {latest_safe.strftime('%Y-%m-%d')} to complete "
   976→   976→   976→                f"manufacturing before CNY shutdown ({cny_start.strftime('%b %d')}–"
   977→   977→   977→                f"{cny_end.strftime('%b %d')})."
   978→   978→   978→            )
   979→   979→   979→        else:
   980→   980→   980→            strategy = CNYStrategy.AFTER_CNY
   981→   981→   981→            additional_delay = cny_total_days
   982→   982→   982→            explanation = (
   983→   983→   983→                f"🔴 CNY RISK: Manufacturing overlaps CNY by {overlap_days} days. "
   984→   984→   984→                f"Cannot finish before CNY. STRATEGY B: Order after CNY on "
   985→   985→   985→                f"{post_cny_order.strftime('%Y-%m-%d')}. Effective delay: {cny_total_days} days. "
   986→   986→   986→                f"Verify safety stock ({safety_stock}) can cover the delay."
   987→   987→   987→            )
   988→   988→   988→        
   989→   989→   989→        return CNYRiskAssessment(
   990→   990→   990→            has_risk=True,
   991→   991→   991→            overlap_days=overlap_days,
   992→   992→   992→            effective_cny_start=effective_cny_start,
   993→   993→   993→            cny_shutdown_start=cny_start,
   994→   994→   994→            cny_shutdown_end=cny_end,
   995→   995→   995→            strategy=strategy,
   996→   996→   996→            additional_delay_days=additional_delay,
   997→   997→   997→            latest_safe_order_date=latest_safe if strategy == CNYStrategy.BEFORE_CNY else None,
   998→   998→   998→            post_cny_order_date=post_cny_order if strategy == CNYStrategy.AFTER_CNY else None,
   999→   999→   999→            explanation=explanation,
  1000→  1000→  1000→        )
  1001→  1001→  1001→    
  1002→  1002→  1002→    # No overlap — safe
  1003→  1003→  1003→    return CNYRiskAssessment(
  1004→  1004→  1004→        has_risk=False, overlap_days=0,
  1005→  1005→  1005→        effective_cny_start=effective_cny_start,
  1006→  1006→  1006→        cny_shutdown_start=cny_start, cny_shutdown_end=cny_end,
  1007→  1007→  1007→        strategy=CNYStrategy.NONE, additional_delay_days=0,
  1008→  1008→  1008→        latest_safe_order_date=None, post_cny_order_date=None,
  1009→  1009→  1009→        explanation=f"✅ No CNY risk. Manufacturing completes before CNY window "
  1010→  1010→  1010→                    f"({cny_start.strftime('%b %d')}–{cny_end.strftime('%b %d')}).",
  1011→  1011→  1011→    )

  1014→  1014→  1014→def _build_timeline(
  1015→  1015→  1015→    order_trigger_date: date,
  1016→  1016→  1016→    mfg_days: int,
  1017→  1017→  1017→    shipment_days: int,
  1018→  1018→  1018→    customs_days: int,
  1019→  1019→  1019→    order_processing_days: int,
  1020→  1020→  1020→    packing_loading_days: int,
  1021→  1021→  1021→    warehouse_transport_days: int,
  1022→  1022→  1022→    qc_shelving_days: int,
  1023→  1023→  1023→    cny_delay_days: int,
  1024→  1024→  1024→) -> OrderTimeline:
  1025→  1025→  1025→    """Build the complete order-to-availability timeline."""
  1026→  1026→  1026→    
  1027→  1027→  1027→    d = order_trigger_date
  1028→  1028→  1028→    total = 0
  1029→  1029→  1029→    
  1030→  1030→  1030→    # Order processing
  1031→  1031→  1031→    order_processing_end = d + timedelta(days=order_processing_days)
  1032→  1032→  1032→    total += order_processing_days
  1033→  1033→  1033→    
  1034→  1034→  1034→    # Manufacturing (including any CNY delay)
  1035→  1035→  1035→    mfg_start = order_processing_end
  1036→  1036→  1036→    effective_mfg_days = mfg_days + cny_delay_days
  1037→  1037→  1037→    mfg_complete = mfg_start + timedelta(days=effective_mfg_days)
  1038→  1038→  1038→    total += effective_mfg_days
  1039→  1039→  1039→    
  1040→  1040→  1040→    # Packing & loading
  1041→  1041→  1041→    packing_end = mfg_complete + timedelta(days=packing_loading_days)
  1042→  1042→  1042→    total += packing_loading_days
  1043→  1043→  1043→    
  1044→  1044→  1044→    # Shipment
  1045→  1045→  1045→    ship_departure = packing_end
  1046→  1046→  1046→    arrival = ship_departure + timedelta(days=shipment_days)
  1047→  1047→  1047→    total += shipment_days
  1048→  1048→  1048→    
  1049→  1049→  1049→    # Customs
  1050→  1050→  1050→    customs_start = arrival
  1051→  1051→  1051→    customs_clearance = customs_start + timedelta(days=customs_days)
  1052→  1052→  1052→    total += customs_days
  1053→  1053→  1053→    
  1054→  1054→  1054→    # Warehouse transport
  1055→  1055→  1055→    warehouse_arrival = customs_clearance + timedelta(days=warehouse_transport_days)
  1056→  1056→  1056→    total += warehouse_transport_days
  1057→  1057→  1057→    
  1058→  1058→  1058→    # QC + shelving
  1059→  1059→  1059→    available_for_sale = warehouse_arrival + timedelta(days=qc_shelving_days)
  1060→  1060→  1060→    total += qc_shelving_days
  1061→  1061→  1061→    
  1062→  1062→  1062→    return OrderTimeline(

  1442→  1442→  1442→## 5. Recommended Order Quantity Calculator
  1443→  1443→  1443→
  1444→  1444→  1444→### 5.1 Full Implementation
  1445→  1445→  1445→
  1446→  1446→  1446→```python
  1447→  1447→  1447→@dataclass
  1448→  1448→  1448→class QuantityBreakdown:
  1449→  1449→  1449→    """Detailed breakdown of how the recommended qty was calculated."""
  1450→  1450→  1450→    total_needed: int           # forecasted_demand + safety_stock
  1451→  1451→  1451→    total_supply: int           # current_stock + qty_on_order
  1452→  1452→  1452→    gap: int                    # total_needed - total_supply
  1453→  1453→  1453→    eoq: int                    # economic order quantity
  1454→  1454→  1454→    moq: int                    # supplier minimum
  1455→  1455→  1455→    max_stock: int              # warehouse capacity
  1456→  1456→  1456→    pre_constraint_qty: int     # qty before constraints applied
  1457→  1457→  1457→    recommended_qty: int        # final constrained qty
  1458→  1458→  1458→    status: str                 # 'order_needed', 'adequate', 'overstock', 'warehouse_full'
  1459→  1459→  1459→    constraints_applied: List[str]  # Which constraints were active
  1460→  1460→  1460→    reason: str                 # Human-readable explanation
  1461→  1461→  1461→
  1462→  1462→  1462→
  1463→  1463→  1463→def calculate_recommended_qty(
  1464→  1464→  1464→    forecasted_demand: int,
  1465→  1465→  1465→    safety_stock: int,
  1466→  1466→  1466→    current_stock: int,
  1467→  1467→  1467→    qty_on_order: int,
  1468→  1468→  1468→    eoq: int,
  1469→  1469→  1469→    moq: int,
  1470→  1470→  1470→    max_stock: int,
  1471→  1471→  1471→) -> dict:
  1472→  1472→  1472→    """
  1473→  1473→  1473→    Calculate the recommended order quantity with full constraint handling.
  1474→  1474→  1474→    
  1475→  1475→  1475→    Algorithm:
  1476→  1476→  1476→    ─────────
  1477→  1477→  1477→    1. Calculate total needed: Forecasted Demand + Safety Stock
  1478→  1478→  1478→    2. Calculate total supply: Current Stock + On Order
  1479→  1479→  1479→    3. Calculate gap: total_needed - total_supply
  1480→  1480→  1480→    4. If gap <= 0 → No order needed (adequate stock)
  1481→  1481→  1481→    5. If currently overstocked → No order, allow draw-down
  1482→  1482→  1482→    6. Start with qty = max(gap, EOQ) → economic batch optimization
  1483→  1483→  1483→    7. Apply MOQ constraint: qty = max(qty, MOQ)
  1484→  1484→  1484→    8. Apply warehouse cap: qty = min(qty, max_stock - current_stock)
  1485→  1485→  1485→    9. If final qty < MOQ and warehouse can't fit MOQ → warehouse_full
  1486→  1486→  1486→    10. Return final qty with full breakdown
  1487→  1487→  1487→    
  1488→  1488→  1488→    Args:
  1489→  1489→  1489→        forecasted_demand: Total forecasted demand for planning period
  1490→  1490→  1490→        safety_stock: Minimum safety stock level
  1491→  1491→  1491→        current_stock: Current available inventory
  1492→  1492→  1492→        qty_on_order: Units already on order (in pipeline)
  1493→  1493→  1493→        eoq: Economic Order Quantity (optimal batch size)
  1494→  1494→  1494→        moq: Supplier Minimum Order Quantity
  1495→  1495→  1495→        max_stock: Maximum warehouse capacity for this SKU
  1496→  1496→  1496→    
  1497→  1497→  1497→    Returns:
  1498→  1498→  1498→        Dictionary with recommended_qty, status, and full breakdown
  1499→  1499→  1499→    """
  1500→  1500→  1500→    constraints_applied = []
  1501→  1501→  1501→    
  1502→  1502→  1502→    # Step 1-3: Calculate demand gap
  1503→  1503→  1503→    total_needed = forecasted_demand + safety_stock
  1504→  1504→  1504→    total_supply = current_stock + qty_on_order
  1505→  1505→  1505→    gap = total_needed - total_supply
  1506→  1506→  1506→    
  1507→  1507→  1507→    # Step 4: Check if stock is adequate
  1508→  1508→  1508→    if gap <= 0:
  1509→  1509→  1509→        return {
  1510→  1510→  1510→            'recommended_qty': 0,
  1511→  1511→  1511→            'status': 'adequate',
  1512→  1512→  1512→            'reason': f'Stock sufficient. Supply ({total_supply}) covers need ({total_needed}).',
  1513→  1513→  1513→            'gap': gap,
  1514→  1514→  1514→            'eoq': eoq,
  1515→  1515→  1515→            'moq': moq,
  1516→  1516→  1516→            'max_stock': max_stock,
  1517→  1517→  1517→            'constraints_applied': [],
  1518→  1518→  1518→            'total_needed': total_needed,
  1519→  1519→  1519→            'total_supply': total_supply,
  1520→  1520→  1520→        }
  1521→  1521→  1521→    
  1522→  1522→  1522→    # Step 5: Check overstock
  1523→  1523→  1523→    if current_stock > max_stock:
  1524→  1524→  1524→        return {
  1525→  1525→  1525→            'recommended_qty': 0,
  1526→  1526→  1526→            'status': 'overstock',
  1527→  1527→  1527→            'reason': f'Currently overstocked ({current_stock} > max {max_stock}). Allow draw-down.',
  1528→  1528→  1528→            'gap': gap,
  1529→  1529→  1529→            'eoq': eoq,
  1530→  1530→  1530→            'moq': moq,
  1531→  1531→  1531→            'max_stock': max_stock,
  1532→  1532→  1532→            'constraints_applied': ['overstock_drawdown'],
  1533→  1533→  1533→            'total_needed': total_needed,
  1534→  1534→  1534→            'total_supply': total_supply,
  1535→  1535→  1535→        }
  1536→  1536→  1536→    
  1537→  1537→  1537→    # Step 6: Start with economic quantity
  1538→  1538→  1538→    qty = max(gap, eoq)
  1539→  1539→  1539→    if eoq > gap:
  1540→  1540→  1540→        constraints_applied.append(f'eoq_floor: EOQ ({eoq}) > gap ({gap}), using EOQ')
  1541→  1541→  1541→    
  1542→  1542→  1542→    # Step 7: Apply MOQ constraint
  1543→  1543→  1543→    if qty < moq:
  1544→  1544→  1544→        qty = moq
  1545→  1545→  1545→        constraints_applied.append(f'moq_floor: qty raised to MOQ ({moq})')
  1546→  1546→  1546→    
  1547→  1547→  1547→    pre_constraint_qty = qty
  1548→  1548→  1548→    
  1549→  1549→  1549→    # Step 8: Apply warehouse capacity constraint
  1550→  1550→  1550→    warehouse_capacity_remaining = max_stock - current_stock
  1551→  1551→  1551→    if qty > warehouse_capacity_remaining:
  1552→  1552→  1552→        qty = warehouse_capacity_remaining
  1553→  1553→  1553→        constraints_applied.append(
  1554→  1554→  1554→            f'warehouse_cap: qty reduced from {pre_constraint_qty} to {qty} '
  1555→  1555→  1555→            f'(max_stock {max_stock} - current {current_stock})'
  1556→  1556→  1556→        )
  1557→  1557→  1557→    
  1558→  1558→  1558→    # Step 9: Check if warehouse can't even fit MOQ
  1559→  1559→  1559→    if qty < moq and qty > 0:
  1560→  1560→  1560→        return {
  1561→  1561→  1561→            'recommended_qty': 0,
  1562→  1562→  1562→            'status': 'warehouse_full',
  1563→  1563→  1563→            'reason': f'Insufficient warehouse space for MOQ. '
  1564→  1564→  1564→                      f'Available space: {warehouse_capacity_remaining}, MOQ: {moq}.',
  1565→  1565→  1565→            'gap': gap,
  1566→  1566→  1566→            'eoq': eoq,
  1567→  1567→  1567→            'moq': moq,
  1568→  1568→  1568→            'max_stock': max_stock,
  1569→  1569→  1569→            'constraints_applied': constraints_applied + ['warehouse_below_moq'],
  1570→  1570→  1570→            'total_needed': total_needed,
  1571→  1571→  1571→            'total_supply': total_supply,
  1572→  1572→  1572→        }
  1573→  1573→  1573→    
  1574→  1574→  1574→    # Ensure qty is non-negative
  1575→  1575→  1575→    qty = max(0, qty)
  1576→  1576→  1576→    
  1577→  1577→  1577→    status = 'order_needed' if qty > 0 else 'adequate'
  1578→  1578→  1578→    reason = f'Order {qty} units. Gap: {gap}, constrained by: {constraints_applied or "none"}'
  1579→  1579→  1579→    
  1580→  1580→  1580→    return {
  1581→  1581→  1581→        'recommended_qty': qty,
  1582→  1582→  1582→        'status': status,
  1583→  1583→  1583→        'reason': reason,
  1584→  1584→  1584→        'gap': gap,
  1585→  1585→  1585→        'eoq': eoq,
  1586→  1586→  1586→        'moq': moq,
  1587→  1587→  1587→        'max_stock': max_stock,
  1588→  1588→  1588→        'constraints_applied': constraints_applied,
  1589→  1589→  1589→        'total_needed': total_needed,
  1590→  1590→  1590→        'total_supply': total_supply,
  1591→  1591→  1591→        'pre_constraint_qty': pre_constraint_qty,
  1592→  1592→  1592→    }
  1593→  1593→  1593→```

  1732→  1732→  1732→    else:  # October
  1733→  1733→  1733→        return 'pre_winter'
  1734→  1734→  1734→
  1735→  1735→  1735→
  1736→  1736→  1736→def get_season_date_range(season: str, year: int) -> tuple:
  1737→  1737→  1737→    """Get start and end dates for a season."""
  1738→  1738→  1738→    ranges = {
  1739→  1739→  1739→        'winter': (date(year, 11, 1), date(year + 1, 2, 28)),
  1740→  1740→  1740→        'summer': (date(year, 3, 1), date(year, 5, 31)),
  1741→  1741→  1741→        'monsoon': (date(year, 6, 1), date(year, 9, 30)),
  1742→  1742→  1742→        'pre_winter': (date(year, 10, 1), date(year, 10, 31)),
  1743→  1743→  1743→    }
  1744→  1744→  1744→    return ranges[season]
  1745→  1745→  1745→
  1746→  1746→  1746→
  1747→  1747→  1747→def apply_seasonal_weight(
  1748→  1748→  1748→    base_demand: float,
  1749→  1749→  1749→    season: str,
  1750→  1750→  1750→    category: str,
  1751→  1751→  1751→) -> float:
  1752→  1752→  1752→    """
  1753→  1753→  1753→    Apply seasonal weighting to base demand.
  1754→  1754→  1754→    
  1755→  1755→  1755→    Uses category-specific weights if available, 
  1756→  1756→  1756→    otherwise falls back to general seasonal weights.
  1757→  1757→  1757→    """
  1758→  1758→  1758→    # Try category-specific first
  1759→  1759→  1759→    if category in CATEGORY_SEASONAL_ADJUSTMENTS:
  1760→  1760→  1760→        weight = CATEGORY_SEASONAL_ADJUSTMENTS[category].get(
  1761→  1761→  1761→            season, SEASONAL_WEIGHTS.get(season, 1.0)
  1762→  1762→  1762→        )
  1763→  1763→  1763→    else:
  1764→  1764→  1764→        weight = SEASONAL_WEIGHTS.get(season, 1.0)
  1765→  1765→  1765→    
  1766→  1766→  1766→    return base_demand * weight
  1767→  1767→  1767→```

  1769→  1769→  1769→### 6.3 How to Predict "Next Winter Best Products"
  1770→  1770→  1770→
  1771→  1771→  1771→```python
  1772→  1772→  1772→def predict_season_best_products(
  1773→  1773→  1773→    products: List[dict],        # List of product records with forecast data
  1774→  1774→  1774→    target_season: str,          # 'winter', 'summer', 'monsoon', 'pre_winter'
  1775→  1775→  1775→    target_year: int,
  1776→  1776→  1776→    current_stock_by_sku: dict,  # {sku_code: current_stock}
  1777→  1777→  1777→    safety_stock_by_sku: dict,   # {sku_code: safety_stock}
  1778→  1778→  1778→    supplier_lead_times: dict,   # {supplier_id: mfg_days}
  1779→  1779→  1779→    today: Optional[date] = None,
  1780→  1780→  1780→    top_n: int = 20,
  1781→  1781→  1781→) -> List[dict]:
  1782→  1782→  1782→    """
  1783→  1783→  1783→    Predict the best products for an upcoming season.
  1784→  1784→  1784→    
  1785→  1785→  1785→    Algorithm:
  1786→  1786→  1786→    1. Filter products by season compatibility (season_type matches target or 'all_season')
  1787→  1787→  1787→    2. For each product, apply seasonal weight to forecasted demand
  1788→  1788→  1788→    3. Rank by: adjusted_demand (forecasted_demand × seasonal_weight)
  1789→  1789→  1789→    4. For top N, calculate order trigger date and recommended qty
  1790→  1790→  1790→    5. Sort by urgency (critical first), then by adjusted_demand descending
  1791→  1791→  1791→    
  1792→  1792→  1792→    Returns:
  1793→  1793→  1793→        List of product recommendations with full order trigger analysis
  1794→  1794→  1794→    """
  1795→  1795→  1795→    if today is None:
  1796→  1796→  1796→        today = date.today()
  1797→  1797→  1797→    
  1798→  1798→  1798→    season_start, season_end = get_season_date_range(target_season, target_year)
  1799→  1799→  1799→    
  1800→  1800→  1800→    # Get CNY window that affects this season's orders
  1801→  1801→  1801→    cny = get_cny_for_date(season_start)
  1802→  1802→  1802→    cny_start = cny['shutdown_start'] if cny else None
  1803→  1803→  1803→    cny_end = cny['shutdown_end'] if cny else None
  1804→  1804→  1804→    
  1805→  1805→  1805→    recommendations = []
  1806→  1806→  1806→    
  1807→  1807→  1807→    for product in products:
  1808→  1808→  1808→        # Step 1: Season compatibility filter
  1809→  1809→  1809→        if product.get('season_type') not in (target_season, 'all_season'):
  1810→  1810→  1810→            continue
  1811→  1811→  1811→        
  1812→  1812→  1812→        sku = product['sku_code']
  1813→  1813→  1813→        category = product.get('category', 'general')
  1814→  1814→  1814→        base_demand = product.get('forecasted_demand', 0)
  1815→  1815→  1815→        
  1816→  1816→  1816→        # Step 2: Apply seasonal weight
  1817→  1817→  1817→        adjusted_demand = apply_seasonal_weight(base_demand, target_season, category)
  1818→  1818→  1818→        
  1819→  1819→  1819→        if adjusted_demand <= 0:
  1820→  1820→  1820→            continue
  1821→  1821→  1821→        
  1822→  1822→  1822→        # Step 3: Get parameters
  1823→  1823→  1823→        current_stock = current_stock_by_sku.get(sku, 0)
  1824→  1824→  1824→        safety_stock = safety_stock_by_sku.get(sku, 0)
  1825→  1825→  1825→        supplier_id = product.get('default_supplier_id')
  1826→  1826→  1826→        mfg_days = supplier_lead_times.get(supplier_id, 90) if supplier_id else 90
  1827→  1827→  1827→        
  1828→  1828→  1828→        # Step 4: Calculate order trigger
  1829→  1829→  1829→        trigger_result = calculate_order_trigger(
  1830→  1830→  1830→            sku_code=sku,
  1831→  1831→  1831→            product_name=product.get('name', ''),
  1832→  1832→  1832→            current_stock=current_stock,
  1833→  1833→  1833→            safety_stock=safety_stock,
  1834→  1834→  1834→            max_stock=product.get('max_stock', 500),
  1835→  1835→  1835→            daily_consumption_rate=adjusted_demand / (season_end - season_start).days,
  1836→  1836→  1836→            mfg_days=mfg_days,
  1837→  1837→  1837→            shipment_mode=ShipmentMode.SEA,
  1838→  1838→  1838→            forecasted_demand=int(adjusted_demand),
  1839→  1839→  1839→            qty_on_order=product.get('qty_on_order', 0),
  1840→  1840→  1840→            eoq=product.get('eoq', 100),
  1841→  1841→  1841→            moq=product.get('moq', 50),
  1842→  1842→  1842→            today=today,
  1843→  1843→  1843→            cny_start=cny_start,
  1844→  1844→  1844→            cny_end=cny_end,
  1845→  1845→  1845→        )
  1846→  1846→  1846→        
  1847→  1847→  1847→        recommendations.append({
  1848→  1848→  1848→            'sku_code': sku,
  1849→  1849→  1849→            'name': product.get('name', ''),
  1850→  1850→  1850→            'category': category,
  1851→  1851→  1851→            'season_type': product.get('season_type'),
  1852→  1852→  1852→            'motorcycle_model': product.get('motorcycle_model'),
  1853→  1853→  1853→            'forecasted_demand': base_demand,
  1854→  1854→  1854→            'seasonal_weight': CATEGORY_SEASONAL_ADJUSTMENTS.get(
  1855→  1855→  1855→                category, SEASONAL_WEIGHTS
  1856→  1856→  1856→            ).get(target_season, 1.0),
  1857→  1857→  1857→            'adjusted_demand': round(adjusted_demand, 0),
  1858→  1858→  1858→            'recommended_qty': trigger_result.recommended_qty,
  1859→  1859→  1859→            'order_trigger_date': trigger_result.order_trigger_date,
  1860→  1860→  1860→            'expected_available_date': trigger_result.timeline.available_for_sale_date,
  1861→  1861→  1861→            'urgency': trigger_result.urgency.value,
  1862→  1862→  1862→            'cny_risk': trigger_result.cny_risk.has_risk,
  1863→  1863→  1863→            'cny_strategy': trigger_result.cny_risk.strategy.value,
  1864→  1864→  1864→            'days_until_trigger': trigger_result.days_until_trigger,
  1865→  1865→  1865→            'total_lead_time_days': trigger_result.total_lead_time_days,
  1866→  1866→  1866→        })
  1867→  1867→  1867→    
  1868→  1868→  1868→    # Step 5: Sort by urgency, then by adjusted demand
  1869→  1869→  1869→    urgency_order = {'critical': 0, 'high': 1, 'normal': 2, 'low': 3}
  1870→  1870→  1870→    recommendations.sort(
  1871→  1871→  1871→        key=lambda x: (urgency_order.get(x['urgency'], 99), -x['adjusted_demand'])
  1872→  1872→  1872→    )
  1873→  1873→  1873→    
  1874→  1874→  1874→    return recommendations[:top_n]
  1875→  1875→  1875→```
