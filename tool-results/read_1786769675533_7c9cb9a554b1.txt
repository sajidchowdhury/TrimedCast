     8→## 1. System Integration Architecture
     9→
    10→### 1.1 Service Map
    11→
    12→```
    13→┌──────────────┐     ┌──────────────┐     ┌─────────────────────┐
    14→│  Frontend    │────▶│   Laravel    │────▶│  Python FastAPI     │
    15→│  (Next.js)   │◀────│   (Port 8000)│◀────│  (Port 8001)        │
    16→└──────────────┘     └──────┬───────┘     └─────────────────────┘
    17→                           │
    18→                           ├────▶ PostgreSQL (Port 5432)
    19→                           ├────▶ Redis (Port 6379) [Queue + Cache]
    20→                           └────▶ AI/RAG Service (Port 8002) [LLM + pgvector]
    21→```
    22→
    23→### 1.2 Authentication Summary
    24→
    25→| Service | Auth Method | Details |
    26→|---|---|---|
    27→| Frontend ↔ Laravel | Laravel Sanctum (SPA) | Cookie-based CSRF-protected auth |
    28→| Laravel ↔ Python | API Key + HMAC | Service-to-service, signed requests |
    29→| Laravel ↔ AI/RAG | API Key + Rate Limit | Service-to-service |
    30→| Mobile/3rd Party ↔ Laravel | Laravel Passport (OAuth2) | Token-based for API consumers |
    31→
    32→### 1.3 Common Headers
    33→
    34→| Header | Required | Description |
    35→|---|---|---|
    36→| Authorization | Yes | `Bearer {token}` (Sanctum) or `Bearer {oauth_token}` (Passport) |
    37→| X-Tenant-ID | Auto-set | Set by middleware after auth — clients MUST NOT set manually |
    38→| Accept | Yes | `application/json` |
    39→| Content-Type | Yes (POST/PUT) | `application/json` or `multipart/form-data` (uploads) |

   596→### 3.10 S&OP Lifecycle
   597→
   598→#### GET /api/v1/sop-cycles/current
   599→**Response:** Current cycle with stage statuses, progress percentages, and completion timestamps.
   600→
   601→#### POST /api/v1/sop-cycles
   602→**RBAC:** warehouse_manager, executive  
   603→**Request:** `{ "cycle_name": "Winter 2026 S&OP", "rhythm": "monthly", "period_start": "2025-11-01", "period_end": "2026-02-28" }`

  1148→## 6. WebSocket Events (Real-time Updates)
  1149→
  1150→### 6.1 Channel Structure
  1151→- **Private tenant channel:** `private-tenant.{tenant_id}`
  1152→- **Presence channel (multi-user):** `presence-sop.{sop_cycle_id}`
  1153→
  1154→### 6.2 Events
  1155→
  1156→| Event | Trigger | Payload |
  1157→|---|---|---|
  1158→| `ForecastProgress` | Python service updates progress | `{ job_id, progress_pct, current_product, completed, total }` |
  1159→| `ForecastComplete` | Forecast job finishes | `{ job_id, total_products, avg_mape, duration_seconds }` |
  1160→| `StockAlert` | Inventory crosses threshold | `{ product_id, product_name, alert_type, current_stock, threshold, days_until_stockout }` |
  1161→| `OrderStatusChanged` | PO status transition | `{ purchase_order_id, product_name, old_status, new_status, expected_dates }` |
  1162→| `SOPStageChanged` | S&OP cycle stage advance | `{ cycle_id, cycle_name, old_stage, new_stage, changed_by }` |
  1163→| `ImportProgress` | Data import step completes | `{ import_id, status, rows_processed, rows_total }` |
  1164→| `CNYRiskAlert` | Order trigger date has CNY risk | `{ recommended_order_id, product_name, order_trigger_date, cny_start, cny_end, revised_date }` |
  1165→
  1166→**Alert Types for StockAlert:**
  1167→- `stockout_risk` — qty_available <= safety_stock
  1168→- `reorder_point_crossed` — qty_available <= reorder_point
  1169→- `overstock` — qty_on_hand > max_stock_qty
